# clicc-imaging-system-gui

This project builds upon the CLICC (Cumulative Lifetime Imaging on CMOS-Camera) software developed by Gauthier Rousseau and collaborators.

Original project: https://gitlab.com/groussea/clicc

The software was extended as part of a Master's thesis in Biomedical Engineering. The contributions in this repository are as follows:

- **Measurement acquisition:** Selected functions from the original CLICC software were reused and integrated into the developed application.
- **Graphical user interface:** The graphical user interface was developed as part of this thesis, integrating measurement acquisition, calibration, model fitting, and image analysis into a unified application.
- **Microcontroller firmware:** The original Arduino firmware was adapted for the implemented imaging setup, including hardware triggering and measurement timing.

The original CLICC authors are acknowledged for their foundational work. Copyright notices and applicable license terms for reused software are retained.
